# WT Квесты

Приложение: реальные задачи → РИ → исследуешь ветки как в War Thunder.
Данные (3122 техники, русские названия, 1859 модификаций) уже собраны в `www/data/data.json`.

## Как собрать APK
1. Залей в репозиторий всё из `wt-quests.zip` (распакуй, закинь файлы и папки, включая `.github`).
2. В папку `raw_images/` залей три файла `pack_1.zip`, `pack_2.zip`, `pack_3.zip` (готовые сжатые картинки, каждый меньше 25 МБ — проходят через сайт GitHub).
3. Actions → Build APK → Run workflow. Через 5–8 минут в Artifacts будет `app-debug.apk`.

Картинки сами раскладываются в `www/img/icon|render|mods`, список найденных пишется в `www/data/images.json`. Если картинки техники нет — показывается заглушка.
Свои новые архивы кидай в `raw_images/` с любым именем, кроме `pack_*` — `tools/build_images.py` разберёт их сам по имени файла.

## Баланс
Всё в начале `www/app.js` (объект `CFG`): стоимость исследований (RS), модификаций (MS), цены премиума (GE), награды за квесты, бонус стрика.
Квесты: `www/data/quests.json` (правь текст как хочешь) + добавление своих прямо в приложении.

## Если обновишь базу
`python tools/build_data.py --db vehiclesdb.sqlite3 --ru ru.json` (базу 340 МБ на GitHub не клади, лимит 100 МБ).
